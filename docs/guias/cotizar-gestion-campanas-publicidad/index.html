Cotizar campañas publicitarias separando gestión e inversión

Explica qué paga el cliente por el trabajo y qué paga a la plataforma, con límites de inversión y tareas de seguimiento verificables.

El dinero para anuncios no es tu honorario

Cuando una propuesta dice «campaña por 1.500», el cliente puede interpretar que incluye toda la inversión publicitaria. Separa tres partidas: preparación inicial, servicio de gestión e importe destinado a la plataforma. Siempre que sea viable, el cliente mantiene su cuenta y paga directamente la inversión; así puede revisar cargos, permisos y resultados.

El caso siguiente es hipotético: una plataforma, dos campañas, cuatro variantes de anuncio y una página de destino existente. El cliente facilita imágenes autorizadas y aprueba mensajes. Las cifras no provienen de una referencia de mercado, y el presupuesto no garantiza ventas ni un costo determinado por adquisición.

La gestión mensual del ejemplo suma 224 + 84 + 112 = 420; la preparación inicial añade 140 una sola vez. Si se autoriza una inversión hipotética de 900, el desembolso previsto del primer mes es 560 + 900 = 1.460. Un mes posterior con el mismo alcance sería 420 + 900 = 1.320. Son cantidades antes de impuestos o cargos que correspondan y deben confirmarse por separado.

Define qué se observa y quién decide

Antes del lanzamiento, acuerda el objetivo y el evento que permitiría medirlo: una solicitud enviada, una compra registrada o una visita a una página concreta. Comprueba el recorrido con una prueba identificada como tal. Si faltan accesos, configuración de consentimiento o integración del formulario, registra la dependencia; instalar o modificar esos sistemas puede requerir otro trabajo.

Entrega un registro de campañas, anuncios y cambios, un informe con el período medido y una explicación de sus límites. Distingue datos de la plataforma de ventas confirmadas por el cliente. Una conversión atribuida por una herramienta puede no coincidir con el registro comercial; documenta la ventana de medición usada y evita sumar ambas como ventas independientes.

Controla la inversión sin prometer resultados

Para planificar un período hipotético de treinta días, 900 equivalen a una media de 30 por día. Esa división ayuda a revisar el ritmo de gasto; no sustituye las reglas de presupuesto de la plataforma, que deben consultarse. Escribe el límite autorizado y quién puede aprobar un aumento. Define también qué hacer si la página deja de funcionar o el cliente ya no puede atender solicitudes.

En la reunión mensual, relaciona las decisiones con evidencia: qué mensaje se probó, cuánto se gastó, qué dato falta y qué se propone cambiar. Evita convertir una variación pequeña en una conclusión definitiva. El cliente necesita comprender la incertidumbre para decidir si mantiene, ajusta o detiene la inversión.

Negocia ampliaciones con una cuenta visible

Añadir una tercera campaña no equivale a aumentar únicamente el gasto publicitario. Si exige dos horas de configuración y tres de creatividades, la ampliación hipotética es (2 + 3) × 28 = 140 de trabajo. Cotiza aparte cualquier incremento de inversión y confirma si también aumenta el seguimiento mensual.

  • ¿La propuesta incluye producir imágenes o solo adaptar materiales?
  • ¿Qué acceso conserva el cliente al finalizar el servicio?
  • ¿Cuántas reuniones, informes y nuevas variantes se incluyen?
  • ¿Quién autoriza cambios de presupuesto y pausas?
