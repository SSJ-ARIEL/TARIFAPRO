Cómo preparar un presupuesto de Diseño UI/UX & Gráfico

Especifica número de pantallas o piezas, versiones, licencias de imágenes, archivos editables y rondas de cambios. Un diseño con transferencia de derechos puede requerir condiciones distintas de una pieza de uso limitado.

Un presupuesto de identidad visual comienza por dónde se utilizará la marca. Pregunta si habrá impresión, redes, envases o interfaces; cada soporte puede requerir archivos y comprobaciones diferentes. La entrega de editables y las licencias de terceros deben quedar expresadas. No presupongas que pagar una pieza da acceso ilimitado a cualquier tipografía o fotografía utilizada.

Plantilla de alcance para completar con el cliente

Copia las tareas que correspondan a tu proyecto y sustituye cada descripción por una cantidad, formato, fecha y responsable concretos. Si una tarea no se incluye, anótala como exclusión para que la propuesta pueda revisarse antes de empezar.

Preguntas que debes resolver antes de cotizar

  • ¿Qué formatos, tamaños y versiones necesita el cliente?
  • ¿Cuántas propuestas iniciales y revisiones están incluidas?
  • ¿Se entregan archivos editables y qué permisos de uso se transfieren?
  • ¿Habrá que comprar recursos visuales o tipografías?

Cuándo volver a presupuestar

Una nueva propuesta completa después de aprobar una dirección visual no es lo mismo que ajustar espaciado o color. Define qué constituye una ronda de comentarios, quién consolida las decisiones y cuándo un cambio requiere otra propuesta.

Usa la calculadora de tarifas con tus costos reales y el generador de propuestas para anotar alcance, plazos y condiciones. Revisa el alcance concreto de tu trabajo y adapta los valores de ejemplo antes de presupuestar.
